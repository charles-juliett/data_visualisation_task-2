# Blue Kiln: online shop cart

A front-end only shop (HTML, CSS, JavaScript). The only server is an npm-based local one.

## Run

```
npm install
npm start
```

Then open http://localhost:3000.

## Features

- 6 products with prices
- Add a product to the cart
- Change the quantity with + and - buttons (a product is removed when it reaches 0)
- Cart shows the list of selected products, line sums and the total
- Cart is kept in localStorage, so it survives a page reload
